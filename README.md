# 聊天站

> **已经上线，直接用：<https://real-benguo.github.io/chat-site/>**

一个 WhatsApp 风格的聊天网站。文字 + 图片，搜名字加好友，**消息端到端加密**，现在有了**账号密码**。

**零成本、零服务器**：不需要买服务器、不需要数据库。前端放 GitHub Pages，消息走公共 MQTT 中转。

---

## 有什么功能

| | |
|---|---|
| 💬 | 文字消息、图片消息（自动压缩） |
| 👤 | **账号密码**：注册后换手机用「名字 + 密码」登录，聊天记录全找回 |
| 🔍 | 搜名字加好友（不用对方同意） |
| ↩️ | **撤回消息**：发出去 48 小时内都能撤，撤了服务器上的原文也真删掉 |
| 🗑️ | **删除消息**：只删自己这台设备上的，对方不受影响 |
| 🔗 | 网址自动变成可点的链接 |
| 💬 | **引用回复**：长按消息 → 回复 |
| 📋 | **复制**、**转发**给其他好友 |
| ⌨️ | **正在输入…** 提示 |
| ✓✓ | 已读回执（可以关掉） |
| 📌 | 聊天置顶、清空聊天记录 |
| 🔒 | 端到端加密 + 加密验证码 + 内容安全策略（CSP） |
| 🌙 | 深色模式 |

长按消息（手机）/ 右键消息（电脑）就能看到全部操作。

## 怎么用

1. 打开网址 → **注册**：起个名字 + 设个密码（至少 8 位）
2. 搜索框输入对方的**完整名字** → 回车 → 点结果 → 开聊
3. 换手机了？打开网址 → **登录** → 输名字 + 密码 → 聊天记录全部回来

**自己一个人怎么试**：开两个浏览器窗口（一个正常 + 一个无痕），各注册一个名字，互相搜。

**想自己先看看安全不安全**：聊天右上角 🔒，两边看到的数字应该完全一样。不一样 = 中间有人动手脚。

## 关于密码（重要，先看再设）

密码不是摆设，它**真的加密着你的聊天密钥**：

- 密码忘了 = **账号找不回来**。没有客服、没有验证码、没有重置链接 —— 这套系统没有服务器能帮你重置
- 换设备靠密码恢复，所以密码丢不得
- 建议设一个你忘不掉的，或者记在只有你自己知道的地方

技术上：密码经过 40 万次 PBKDF2 派生出密钥，用它加密你的聊天私钥后才存到服务器上。服务器上只有密文，拿到也解不开（除非暴力试你的密码 —— 所以密码别太简单）。

**名字就是账号，注册后不能改**（改了别人就搜不到你了）。要换名字就重新注册一个。

## 隐私与安全

- **消息内容**（包括图片）在你手机上加密、到对方手机才解开，中转服务器上全是密文
- **加密验证码**：两边数字一样，说明中间没人偷看
- **撤回是真的撤**：撤回后原文从中转服务器上删除，新登录的人拉不到
- **CSP**：网页被限制只能连自己的文件和那一个消息服务器，就算被注入恶意代码也跑不起来
- **链接只认 http/https**，且全部带 `noopener`，防钓鱼跳转
- **「仅本机删除」不发出任何请求**，对方完全不知道

### 但这些要心里有数

| | |
|---|---|
| **元数据是公开的** | 消息内容读不到，但「谁在什么时候发了几条、多大」在中转服务器上是明文。特别敏感的事别在上面聊 |
| **中转服务器是公共的** | EMQX 免费公共服务器，谁都能连。偶尔会卡、会断、会丢包（程序会自动补），不保证 7×24 稳定 |
| **撤回不是万能的** | 对方可能已经截图，或者正好在线看到了 |
| **公共 broker 有丢包** | 实测约 10% 的消息片首次送不到，程序会自动重订阅补齐（实测能补到 100%），所以偶尔消息会慢几秒 |

## 出问题了？

| 现象 | 原因 |
|---|---|
| 提示「必须用 https」 | 你是双击本地文件打开的。要用网址访问 |
| 左下角一直红字 | 公共服务器抽风或网络不通，等会儿自动重连；不行就刷新 |
| 注册说「名字已经被别人用了」 | 换个名字。名字是唯一的 |
| 登录说「密码不对」 | 密码错了。**没有找回功能**，只能重新注册一个新号 |
| 消息慢几秒才到 | 分片丢了在自动补，正常现象 |
| 图片显示「图片打不开」 | 分片没补全，刷新一下页面会自动补 |
| 撤回按钮是灰的/没有 | 超过 48 小时的消息不能撤 |
| 想彻底重来 | 设置（右上角齿轮）→ 清空本机全部数据 |
